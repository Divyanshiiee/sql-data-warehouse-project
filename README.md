# SQL Data Warehouse & Analytics Project

## 📌 Overview

This project focuses on building an end-to-end Data Warehouse using SQL Server.

The project demonstrates how raw data from different source systems can be collected, stored, cleaned, transformed, integrated, and prepared for analytical reporting.

The data warehouse follows a layered architecture consisting of:

- Bronze Layer – Raw data
- Silver Layer – Cleaned and standardized data
- Gold Layer – Business-ready data

The final data will be used for analytical queries and reporting.

---

## 🎯 Project Objectives

- Build a structured SQL Data Warehouse using SQL Server
- Load raw data from source files into the data warehouse
- Implement a Bronze, Silver, and Gold layer architecture
- Clean and standardize data using SQL
- Transform and integrate data for analytical purposes
- Create business-ready datasets for reporting and analysis
- Develop SQL queries to generate meaningful business insights

---

## 🏗️ Data Warehouse Architecture

The project follows a layered data warehouse architecture:

**Source Systems → Bronze Layer → Silver Layer → Gold Layer → Analytics & Reporting**

### Bronze Layer
Stores raw data from the source systems with minimal or no transformations.

### Silver Layer
Contains cleaned, standardized, and transformed data.

### Gold Layer
Contains business-ready data prepared for analytical queries and reporting.
